The program (`bin/dart_exercises.dart`) implements the following core requirements:

1. **Explicit Data Types:**
   - `String` (`studentName`)
   - `int` (`totalItems`, `bundleSize`, `completeBundles`, `leftoverItems`)
   - `double` (`itemPrice`, `rawTotal`)
   - `bool` (`isVIPMember`, `qualifiesForDiscount`)

2. **Operators Applied:**
   - **Arithmetic Operators:** Multiplication (`*`), Integer Division (`~/` for extra credit), and Modulus (`%` for extra credit).
   - **Comparison Operators:** Greater than (`>`).

3. **Output Generation:**
   - Uses `print()` statements with string interpolation (`$variable`) to present human-readable results rather than bare values.
